		   Grille and Hood all had parent = EngineDoor: the Lua keys damage by parent, so

		   absorbed nothing. Hood -> EngineDoor (the hood IS the engine door). Bumper and
		   Grille -> Engine.
		   NOTE: Bumper and Grille still share Engine as parent, so only one of them draws
		   per hit. There is no distinct vanilla radiator/grille part to parent Grille to.
		   To make all three independent, add a custom hidden front part and repoint Grille
		   to it, or merge Grille into Bumper. Left both defined intentionally. */

		part SCArmor* {

            area = Engine,
            category = SCUCKarmor,
            mechanicRequireKey = false,

            /* Absorption rate read by miscVehicleLua.armorAbsorb.
               damageToArmor = absorbedDamage * damageAbsorptionOneTo.
               1.0 = plate wears 1:1 with damage it blocks. <1.0 = more durable.
               >1.0 = sacrificial. Without this table the Lua returned full damage and no
               plate had any durability advantage. Override per-part for tougher/weaker
               plates (e.g. thin windows > 1.0, hull plate < 0.5). */
            table armorBehavior { damageAbsorptionOneTo = 0.4, damageThreshold = 5, }

            table install
            {
                items {
                    1 { type = Base.Wrench, count = 1, keep = true, equip = primary, }
                    }
                time = 1000,
                skills = Mechanics:2;Metalworking:1,
